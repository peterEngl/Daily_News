# Daily News als Web-App – Umsetzungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Daily News wird eine installierbare Web-App: feste App-Hülle, tägliche Inhaltsdatei `ausgabe.json`, Live-Kurse, Offline-Start, lokal testbar.

**Architecture:** Statische Dateien ohne Build-Schritt. `index.html` ist ein Gerüst mit leeren Containern, `render.js` baut daraus mit DOM-Methoden die Ausgabe aus `ausgabe.json`, `kurse.js` holt alle 60 s Kurse von CoinGecko, `sw.js` speichert die App-Hülle für den Offline-Start. Reine Logik (Formatierung, Prüfung, Kurs-Auswertung) liegt in eigenen Modulen und wird mit `node --test` getestet; Darstellung, Offline und Installation werden im Browser geprüft.

**Tech Stack:** HTML, CSS, JavaScript (ES-Module), Node 20+ nur für Tests (`node:test`, keine Pakete), Python 3.11 als lokaler Server, Edge headless für die Symbole.

**Spec:** `docs/superpowers/specs/2026-11-16-web-app-design.md`

## Global Constraints

- Kein Framework, kein Build-Schritt, keine npm-Abhängigkeiten. `package.json` enthält nur `{"type":"module","private":true}`.
- Alle Pfade relativ (`./…`), weil die App später unter `https://peterengl.github.io/Daily_News/` läuft.
- Inhalte aus `ausgabe.json` nur per `textContent`/`createElement`, **nie `innerHTML`**. Links nur bei `http:`/`https:`.
- Keine externen Schriften oder Skripte; einzige Fremdverbindung ist der Kursabruf bei CoinGecko.
- Sicherheit (Spec „Sicherheit“): CSP-Meta-Tag exakt `default-src 'self'; script-src 'self'; style-src 'self'; font-src 'self'; img-src 'self'; connect-src 'self' https://api.coingecko.com; manifest-src 'self'; worker-src 'self'; object-src 'none'; base-uri 'none'; form-action 'none'`; `<meta name="referrer" content="no-referrer">`; keine Inline-Skripte, keine `style=`-Attribute, keine Inline-Event-Handler; Quellenlinks mit `rel="noopener noreferrer"`; Daten von CoinGecko und aus `localStorage` nur als endliche Zahlen übernehmen.
- Optik bleibt wie die bisherige `index.html` (Design-Spec `2026-11-16-neues-design-design.md`): Hintergrund `#f3ece1`, Akzent `#b3122b`, „Source Sans 3“, Titel „Source Serif 4“, Dunkelmodus nach System.
- „Keine Anlageberatung“ steht immer in der Kurstafel.
- Alle Zeiten und das „heute“ der App in Zeitzone `Europe/Vienna`, unabhängig von der Zeitzone des Geräts.
- Zahlen im deutschen Format mit Punkt als Tausendertrennzeichen (`Intl` mit `de-DE`, nicht `de-AT`, das Leerzeichen trennt).
- Kein Impressum, keine Datenschutzseite in diesem Plan (bewusst verschoben, siehe Spec „Veröffentlichung“, Schritt 0).
- Nichts löschen ohne Peters ausdrückliches OK (`CLAUDE.md`). Nichts pushen.
- **Kontrollpunkt nach jedem Task:** kurz zusammenfassen, was erledigt ist, und Peters Bestätigung abwarten (`CLAUDE.md`, Regel 6).

## Festlegungen dieses Plans (über die Spec hinaus)

- **Laden der Ausgabe:** Nicht der Service Worker, sondern `app.js` lädt `ausgabe.json` (Netz zuerst, `cache: 'no-cache'`) und legt eine Kopie in den Cache-Speicher `daily-news-ausgabe`. Bei Netzfehler liest es die Kopie und weiß so, dass der Hinweis „Offline – gespeicherte Ausgabe“ nötig ist. Der Service Worker lässt `ausgabe.json` und alle fremden Adressen durch. Verhalten wie in der Spec, nur an einer Stelle, an der die Seite den Zustand kennt.
- **Lokaler Server:** `tests/server.py` (nur Standardbibliothek) statt `python -m http.server`, weil Python unter Windows `.js` oft als `text/plain` ausliefert und ES-Module dann nicht laden. Aufruf: `python tests\server.py` → `http://localhost:8000/`.
- **Kursformat:** ab 100 USD ohne Nachkommastellen, ab 1 USD zwei, darunter drei. Kein „ca.“ mehr, weil die Werte live sind.
- **Symbole:** ein Motiv für alle Größen: Fläche ganz in `#b3122b`, „DN“ weiß in Source Serif 4 700, Schrifthöhe ca. 40 % der Kantenlänge, mittig. Dadurch taugt dasselbe Bild auch als maskierbares Symbol.

## Review Focus

1. **Gerät nicht in Wiener Zeit** (Leser im Ausland, Uhr kurz nach Mitternacht UTC) → „heute“, Uhrzeiten und Hinweis müssen trotzdem Wiener Zeit nutzen. Tests in Task 2 (`heuteWien`, `stundeWien` mit UTC-Zeitpunkten, Sommer- und Winterzeit).
2. **HTML oder Skript in einem Text der Ausgabe** (`<img onerror=…>` aus einer Quelle übernommen) → Prüfprogramm lehnt ab; die Seite würde es nur als Text zeigen. Test in Task 1, Browserprüfung in Task 4.
3. **Ressort ohne belegbare Meldungen** (`keineMeldungen` gesetzt, Listen leer) → Ressort zeigt nur den Hinweis, kein leeres Raster, Navigation bleibt. Test in Task 1, Browserprüfung in Task 4.
4. **CoinGecko liefert Fehler, Ratenlimit (429) oder eine Münze fehlt** → letzte Werte bleiben, Hinweis „derzeit keine Verbindung“; eine fehlende Münze zeigt „–“ statt Absturz. Tests in Task 5.
5. **`localStorage` oder Cache-Speicher nicht verfügbar** (privater Modus) → App funktioniert, nur ohne gespeicherte Werte; alle Zugriffe in `try/catch`. Browserprüfung in Task 5.
6. **Manipulierte Fremddaten** (Kursantwort oder `localStorage` enthält Text statt Zahl, z. B. `"<script>"`) → wird als „–“ angezeigt, nie als Markup. Tests in Task 5.

**Files:**

**Interfaces:**

Schema (verbindlich, aus der Spec):
- oben: `nummer` (ganze Zahl ≥ 1), `datum` (gültiges `JJJJ-MM-TT`), `redaktionsschluss` (`HH:MM`), `aufmacher`, `termine`, `ressorts`.
- `aufmacher`: `ressort` (Text), `titel`, `vorspann`, `absaetze` (≥ 1 Text), `quellen`.
- `termine`: Liste von `{datum, text}`; jedes `datum` gültig und ≥ Ausgabedatum.
- `ressorts`: genau drei, `id` in Reihenfolge `ki`, `games`, `krypto`, je `titel`.
  - Wenn `keineMeldungen` ein nicht leerer Text ist: `hauptartikel` muss `null` sein, `artikel` und `kurzmeldungen` leer.
  - Sonst `keineMeldungen` = `null`, `hauptartikel` = Artikel, `artikel` und `kurzmeldungen` Listen (dürfen leer sein).
- Artikel: `dachzeile`, `titel`, `absaetze` (≥ 1), `quellen`. Kurzmeldung: `titel`, `text`, `quellen`.
- `quellen`: ≥ 1 Eintrag `{name, url}`, `url` beginnt mit `https://` und ist per `new URL()` gültig.
- Alle Texte nicht leer (nach `trim`) und ohne `<` oder `>`.
